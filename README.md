# ⭐ Stelle Cadenti

Un piccolo gioco arcade in un singolo file HTML: prendi le stelle che cadono e schiva i meteoriti.

## Come si gioca

- Muovi il **mouse** (o il dito su touch screen) oppure usa le frecce **← →** per spostare la barra.
- Prendi le **stelle gialle** per fare punti.
- Schiva i **meteoriti rossi**: hai **3 vite**.
- Premi **Spazio** o clicca per iniziare e per rigiocare.
- Con il passare del tempo la caduta accelera e i meteoriti aumentano.

Il tuo record viene salvato nel browser (`localStorage`).

## Come avviarlo

Non servono dipendenze né build. Apri `index.html` in un browser moderno.

## Tecnologie

HTML, CSS e JavaScript puro con `<canvas>`.
